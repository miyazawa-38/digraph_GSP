• ノイズ除去は最初に取り組む題材としてかなり適しています。GNNは不要で、まずGSPのフィルタと
  して鎌田・村松・Magneticの違いを直接評価できます。

  ただし一番大事なのは、「真の信号」と「人工的に加えたノイズ」を明確に分けることです。

## 基本設定

  真の信号を (x)、ノイズを (n)、観測信号を

  [
  x_{\mathrm{noisy}}=x+n
  ]

  とします。各手法のラプラシアンでローパスフィルタリングし、

  [
  \hat{x}=g(L)x_{\mathrm{noisy}}
  ]

  として、(\hat{x}) が (x) にどれだけ近づいたかを測ります。

  最初に試すフィルタは2種類で十分です。

### Heat kernel

  現在実装済みの

  [
  g_\tau(\lambda)=e^{-\tau\lambda}
  ]

  です。

  [
  \hat{x}

  U\operatorname{diag}(e^{-\tau\lambda_k})U^*
  x_{\mathrm{noisy}}
  ]

### Tikhonovフィルタ

  [
  \hat{x}

  \arg\min_z
  |z-x_{\mathrm{noisy}}|_2^2
  +\alpha z^*Lz
  ]

  で、閉形式は

  [
  \hat{x}=(I+\alpha L)^{-1}x_{\mathrm{noisy}}
  ]

  です。周波数応答は

  [
  g_\alpha(\lambda)=\frac{1}{1+\alpha\lambda}
  ]

  となります。グラフ信号のノイズ除去では非常に基本的な方法です。Signal Denoising on Graphs
  via Graph Filtering (<https://users.ece.cmu.edu/~asandryh/papers/globalsip14.pdf>)

  プロジェクトにはすでに filterTikhonov.m があるので利用できます。

## 実験用の真の信号

  一種類だけでは結論が偏るので、次の3段階がよいです。

### 1. 人工的な滑らかな信号

  既知の低周波固有ベクトルを使い、

  [
  x=\sum_{k=1}^{K}c_k u_k
  ]

  として真の信号を作ります。

  これは「理論どおりローパスフィルタが機能するか」を確かめる最小実験です。

  ただし、鎌田法の固有ベクトルから作った信号を鎌田法で復元すれば、鎌田法が有利になるのは当
  然です。そのため、

- 鎌田法から生成
- 村松法から生成
- Magnetic法から生成
- 無向ラプラシアンから生成

  をすべて行い、「信号生成法 × ノイズ除去法」の表にする必要があります。

### 2. 小規模グラフ上の意味が明確な信号

  一方向パスや有向スター上で、例えば

- 線形に増加する信号
- 送信元だけ大きい信号
- 送信方向に沿って減衰する信号
- いくつかの領域で区分一定な信号

  を作ります。

  これにより、各手法がどの形状を保存し、どの形状をノイズと判断するかを説明できます。

### 3. メールデータの活動量信号

  現在の

  [
  x_i=\text{頂点 (i) の総送信数}
  ]

  を真値とみなし、人工ノイズを加えます。

  全期間のメール数は観測データなので厳密な「無雑音真値」ではありませんが、手法比較用の疑似
  真値としては使えます。

  より自然にするなら、日ごとまたは週ごとの活動量 (x(t)) を作り、各時点の信号にノイズを加え
  て、多数の時刻で平均性能を測ります。

## 加えるノイズ

  最初はGaussianノイズで十分です。

  [
  n\sim\mathcal{N}(0,\sigma^2I)
  ]

  ただし、(\sigma) を直接指定するより入力SNRで制御すると比較しやすいです。

  [
  n\leftarrow
  n\sqrt{
  \frac{|x|_2^2}
  {10^{\mathrm{SNR}{\mathrm{in}}/10}|n|_2^2}
  }
  ]

  例えば次を試します。

  [
  \mathrm{SNR}_{\mathrm{in}}
  \in{0,5,10,15,20}\ \mathrm{dB}
  ]

  その後、メール数の性質に合わせて次も追加できます。

- インパルスノイズ：一部の頂点だけ異常に大きい
- Poissonノイズ：カウントデータ向け
- 欠損とノイズの混在
- 特定の高次数頂点だけにノイズ
- 送信側・受信側に偏ったノイズ

  研究の第一段階ではGaussianノイズだけで構いません。

## パラメータの選び方

  3手法すべてに同じ (\tau=3) を使うだけでは公平とは限りません。固有値分布が異なるため、同じ
  (\tau) でもフィルタの強さが変わるからです。

  例えば

  [
  \tau\in{10^{-3},10^{-2.5},\ldots,10^2}
  ]

  または同様の範囲で (\alpha) を探索し、各手法について最良値を選びます。

  最初の基礎実験では、真値が分かっているので「RMSEを最小にしたoracleパラメータ」を使って構
  いません。その後、実用実験では訓練期間・検証期間・評価期間に分け、検証データでパラメータ
  を選びます。

  比較すべきなのは、

- 固定パラメータでの性能
- 各手法を最適化した場合の最高性能
- パラメータ変化に対する安定性

  の3点です。

## 評価指標

  最低限、次を記録します。

### RMSE

  [
  \mathrm{RMSE}

  \sqrt{\frac{1}{N}|\hat{x}-x|_2^2}
  ]

### 相対誤差

  [
  \mathrm{RE}

  \frac{|\hat{x}-x|_2}{|x|_2}
  ]

### SNR改善量

  [
  \Delta\mathrm{SNR}

  10\log_{10}
  \frac{|x_{\mathrm{noisy}}-x|_2^2}
  {|\hat{x}-x|_2^2}
  ]

  正ならノイズ除去に成功、負なら処理前より悪化しています。

  加えて、

- 処理前後のTV
- 出力ノルム
- 虚部の比率
- 高周波エネルギーの減衰量

  も保存します。

  乱数を変えて30～100回程度繰り返し、平均と標準偏差を出すのが重要です。

## 複素出力をどう評価するか

  この研究では、ここが最大の論点です。入力 (x) は実数ですが、エルミートラプラシアンで処理す
  ると (\hat{x}) は複素数になります。

  最初は次の3通りを別々に評価すべきです。

  [
  \hat{x}_{\mathrm{complex}}=\hat{x}
  ]

  [
  \hat{x}_{\mathrm{real}}=\operatorname{Re}(\hat{x})
  ]

  [
  \hat{x}_{\mathrm{magnitude}}=|\hat{x}|
  ]

  そして、

  [
  r_{\mathrm{imag}}

  \frac{|\operatorname{Im}\hat{x}|_2}
  {|\hat{x}|_2}
  ]

  も報告します。

  abs を取った結果だけを出すと、位相を捨てたことで性能が良くなったのか、ラプラシアンが本当
  に有効なのか分からなくなります。

  また、メール数は非負なので、実用的な出力として

  [
  \hat{x}_{+}=\max(0,\operatorname{Re}\hat{x})
  ]

  も考えられます。ただし、これは後処理ありの結果として明示します。

## 必要な比較手法

  最低限、次の5つを比較すると研究としてまとまります。

  1. フィルタなし
  2. 無向化した (W=(A+A^\top)/2) の通常ラプラシアン
  3. 鎌田法
  4. 村松法
  5. Magnetic法

  「フィルタなし」は、実際に誤差が改善したか確認する基準です。通常の無向ラプラシアンは、
  「有向性を使う意味があったか」を判断する基準になります。

## 有向性が効いているかを確かめる実験

  同じ信号とノイズに対し、次のグラフを使います。

- 元の (A)
- 全辺を反転した (A^\top)
- 無向化した ((A+A^\top)/2)
- 方向をランダムに入れ替えたグラフ

  もし結果がほとんど変わらなければ、そのノイズ除去では方向情報が利用されていません。

  逆に鎌田法の性能や出力位相が辺反転によって系統的に変われば、「方向を認識したノイズ除去」
  の証拠になります。

## おすすめの実施順

  まず次の小さな実験を完成させるのがよいです。

  1. Dept1の送信数を真の信号 (x) とする
  2. 入力SNRを0、5、10、15、20 dBとする
  3. 各条件でGaussianノイズを30回生成
  4. 正規化ラプラシアンを全手法で使用
  5. Heat kernelの (\tau) を対数スケールで探索
  6. RMSE、SNR改善量、虚部比率を測定
  7. 無向法を含む4手法を比較
  8. 最後に (A)、(A^\top)、無向化グラフを比較

  この実験を終えた後に、人工低周波信号と週単位の活動量へ広げます。

  最初の研究質問は、次の形が明確です。

  > 有向メールネットワーク上の送信活動量に対して、鎌田エルミートラプラシアンによるローパス
  > フィルタは、無向・村松・Magneticラプラシアンより高いノイズ除去性能を示すか。また、その
  > 性能に方向情報と複素位相はどのように寄与するか。

  なお、有向グラフ用の別のエルミートラプラシアンでも、ノイズ除去を応用例にした研究がありま
  す。Haar-Laplacian for directed graphs (<https://arxiv.org/abs/2411.15527>)
  そのため、ノイズ除去を鎌田法の評価課題にする方向性自体は自然です。
