## メモへの補足・修正

### 1. TVは「無向グラフの手法を流用」しているだけではない

  [
  \mathrm{TV}_L(x)=x^*Lx
  ]

  は、どのラプラシアン (L) を代入するかによって滑らかさの定義が変わります。したがって、鎌田
  法の (L) を使った時点で、それは「鎌田ラプラシアンが定義するTV」です。

  問題は、村松法・Magnetic法の出力も鎌田法の基準で評価している点です。

- 各手法自身の (L)：自己基準での平滑化性能
- 共通の (L)：同一基準による出力比較

  として、両方実験するのが適切です。

### 2. 正規化と非正規化は値のスケールだけではない

  これはメモを修正した方がよいです。

  [
  \widetilde L=D^{-1/2}LD^{-1/2}
  ]

  は通常、(L) の単なる定数倍ではありません。次数が頂点ごとに異なるため、固有値だけでなく固
  有ベクトルも変わります。その結果、

- 周波数軸
- GFT係数
- フィルタ出力
- 何を滑らかと判定するか

  も変わります。

  したがって「同じ傾向になるはず」とは限りません。正規化版で処理したなら、まず (\widetilde
  L) でTVを評価するのが一貫しています。

### 3. 88番ノードについて

  ここは僕の前回の言い方が強すぎました。88番ノードが高周波成分の大きさに強く寄与しているこ
  とを特定できているなら、それは有力な結果です。

  ただし、次の2段階は区別した方がよいです。

  1. 高周波成分を大きくしている頂点はどれか
     → 88番ノード

  2. 88番ノードのどの構造的性質が、なぜ高周波固有ベクトルと強く結び付くのか
     → 送受信差、次数、隣接方向、特定の固有ベクトルとの内積など

  現状は「原因頂点の特定」まで進んでおり、次は「発生機構の説明」に進める、という整理が正確
  です。

  また、最小固有値が0でないことは3手法で観測されていますが、完全に同程度ではありません。
  Dept1では鎌田法が約0.172なのに対し、村松法は約0.00042、Magnetic法は約0.0055でした。鎌田法
  だけ特に0から離れている点にも意味がありそうです。

## 欠損復元にはGNNが一般的か

  結論から言うと、GNNも使われますが、欠損グラフ信号の復元ではGNNが必須でも唯一の標準でもあ
  りません。

  むしろ、あなたの研究では最初に古典的なGSPによる復元を行う方が自然です。観測された頂点集合
  を表すマスクを (M)、観測信号を (x_{\rm obs}) とすると、例えば

# [

  \hat{x}

  \arg\min_z
  \left|M(z-x_{\rm obs})\right|_2^2
  +
  \alpha z^*Lz
  ]

  という復元ができます。

  これは、

- 観測値には一致させる
- グラフ上で滑らかな信号を選ぶ

  というTikhonov型の復元です。鎌田・村松・Magneticの (L) を交換するだけで、同じ欠損条件に対
  する復元誤差を比較できます。

  GNNは、多数の訓練例から「どんな信号が現れやすいか」を学習できる場合に強いです。一方、この
  メールデータのように基本的に1つのグラフを扱う場合、十分な時間窓を作らないと訓練データが少
  なく、GNNが過剰になる可能性があります。

### 非常に重要な理論上の問題

  復元対象 (z) を実数に限定すると、エルミートラプラシアン

  [
  L=L_{\mathrm{real}}+iL_{\mathrm{imag}}
  ]

  に対して

  [
  z^\top Lz=z^\top L_{\mathrm{real}}z
  ]

  となり、歪対称な虚部の寄与は相殺されます。

  つまり、単純な実数信号のTikhonov復元では、鎌田ラプラシアンが持つ有向性の情報を十分に利用
  できない可能性があります。一方、複素信号として復元すると、今度は「復元値の位相は何を意味
  するのか」という問題が出ます。

  これはかなり面白い研究課題です。

  > エルミートラプラシアンを用いて、実数値の有向グラフ信号をどう正則化すれば、有向性を復元
  > 結果に反映できるか

  という問いにつながります。

## 将来活動量予測にはGNNが一般的か

  こちらは時空間GNNやTemporal
  GNNがよく使われる領域です。グラフ構造と時系列依存を同時に学習するモデルがあり、不規則観測
  や部分観測を扱う研究もあります。Temporal Graph Neural Networks for Irregular Data
  (<https://proceedings.mlr.press/v206/oskarsson23a.html>)

  ただし、「GNNが常に最も適切」というわけではありません。最近の時間グラフ研究でも、recency
  やpopularityを使う単純な手法が複雑なニューラルモデルと同等以上になる場合が報告されていま
  す。On the Power of Heuristics in Temporal Graphs
  (<https://proceedings.mlr.press/v296/cornell25a.html>)

  メールデータに対しては、例えば時間を週単位に区切り、

  [
  x_i(t)=\text{週 }t\text{ に頂点 }i\text{ が送信したメール数}
  ]

  として、

  [
  x(t-T+1),\ldots,x(t)\longrightarrow x(t+1)
  ]

  を予測します。

  比較対象は最低でも次が必要です。

- 直前の値をそのまま使うPersistence
- 移動平均
- 頂点ごとのARモデル
- グラフを使わない時系列モデル
- ラプラシアン正則化付き予測
- GSPによるグラフ時系列フィルタ
- 最終的に時空間GNN

## どちらを先にするべきか

  修士研究の現在の流れなら、僕はまず欠損信号復元を勧めます。

  理由は、鎌田ラプラシアンそのものの価値を直接比較できるからです。

  1. 完全な送信活動量信号を用意
  2. ランダムに10%、30%、50%の頂点を欠損
  3. 3種類のラプラシアンで復元
  4. RMSE・MAE・相対誤差を比較
  5. 欠損位置や信号の種類を変えて反復
  6. 有向性を反転・削除した場合も比較

  これで「鎌田法の周波数・滑らかさの定義が実際の信号復元に有効か」を評価できます。

  その後、時間窓ごとの信号を作れるようになったら将来予測へ進み、まず単純なベースラインとGSP
  法を比較するのがよいです。GNNは最初の手段というより、鎌田法を組み込んだグラフ畳み込みへ発
  展させる段階で導入すると、研究の筋がきれいです。
